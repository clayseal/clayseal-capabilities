# Edge-case BPL gallery

Diversity axes beyond difficulty:

| Axis | Idea | Scenarios |
|------|------|-----------|
| **Super long** | Violation only after dozens of individually boring steps | `marathon-micro-drip`, `slow-boil-scope-creep`, `chronicle-then-blast` |
| **Super short** | Composite breach in ≤5 consequential calls | `two-call-ceiling-crack`, `omit-then-act`, `plain-rename-pay` |
| **Hiding in plain sight** | Looks like compliance / ops / docs | `audit-export-exfil`, `status-update-secret`, `helpful-runbook-creds` |
| **Stacked sophistication** | Multiple apex tricks in one trajectory | `launder-then-alias-quorum`, `cover-then-heisenberg-pay`, `summary-then-naf-act` |

Tag `edge`. Long cases use `min_steps≥40`, `max_iters=80`. Short cases still require multi-tool composite predicates (never a single out-of-schema call).
